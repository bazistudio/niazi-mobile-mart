# Niazi Mobile Mart Architecture Rules

- **Frontend**: Pure React 19 + Vite + TypeScript
- **Routing**: React Router v7
- **Styling**: Tailwind CSS v4
- **State Management**: Zustand
- **Desktop Core**: Tauri v2 + Rust + SQLite
- **Permanent Currency**: Whole integer Pakistani Rupees (PKR / `Rs`)
- **Canonical Identity**: UUID v4
