# 🏪 Niazi Mobile Mart

Private internal ERP & POS system built for Niazi Mobile Mart.

Designed for **Niazi Mobile Mart**, this application is built to handle:
- Multi-shop management
- Role-based access control
- Real-time POS operations
- Real-time inventory sync
- Scalable SaaS architecture

---

## 🚀 Tech Stack

- React 19
- Vite
- Tauri v2 (Desktop Core)
- TypeScript
- Zustand (State Management)
- Axios (API Layer)
- TailwindCSS

---

## 🧠 Core Features

### 🔐 Authentication System
- JWT + Refresh Token support
- Device binding security
- Role-based access control:
  - SUPER_ADMIN
  - MULTI_ADMIN
  - SHOP_ADMIN
  - STAFF

---

### 🏪 Multi-Shop System
- Organization → Shops → Staff hierarchy
- Shop-scoped data isolation
- Multi-tenant architecture

---

### 💻 Web POS
- Fast cashier checkout
- Real-time stock sync
- Thermal & A4 invoice printing

---

### 🔄 Sync Engine
- Real-time sync engine
- Event-based updates
- Decoupled platform adapter
