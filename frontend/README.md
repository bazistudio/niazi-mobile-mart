# 🏪 TijaratPro ERP

Multi-tenant ERP & POS system built for modern retail businesses.

Built with **Next.js + TypeScript**, TijaratPro is designed to handle:
- Multi-shop management
- Role-based access control
- Real-time POS operations
- Real-time inventory sync
- Scalable SaaS architecture

---

## 🚀 Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Zustand (State Management)
- Axios (API Layer)
- TailwindCSS

---

## 🧠 Core Features

### 🔐 Authentication System
- JWT + Refresh Token support
- Device binding security
- Role-based access control:
  - SUPER_ADMIN
  - MULTI_ADMIN
  - SHOP_ADMIN
  - STAFF

---

### 🏪 Multi-Shop System
- Organization → Shops → Staff hierarchy
- Shop-scoped data isolation
- Multi-tenant architecture

---

### 💻 Web POS
- Fast cashier checkout
- Real-time stock sync
- Thermal & A4 invoice printing

---

### 🔄 Sync Engine
- Real-time sync engine
- Event-based updates
- Decoupled platform adapter
